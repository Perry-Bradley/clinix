\section*{Appendix 1: Full REST API Endpoint Reference}
\addcontentsline{toc}{section}{Appendix 1: Full REST API Endpoint Reference}
\label{app:api-reference}

The Clinix backend exposes the following REST endpoints under the
\texttt{/api/v1/} prefix. All endpoints require a valid JWT
(\texttt{Authorization: Bearer <token>}) unless explicitly marked as
\emph{public}.

\subsection*{A1.1 Authentication}

\begin{longtable}{p{1.4cm} p{6.5cm} p{6.0cm}}
\toprule
\textbf{Method} & \textbf{Path} & \textbf{Purpose} \\
\midrule
\endhead
POST  & \texttt{/auth/register/}                  & Basic email/phone signup (public). \\
POST  & \texttt{/auth/role-selection/}            & Assign \texttt{user\_type} (patient/provider). \\
POST  & \texttt{/auth/register/patient/}          & Patient signup + send OTP. \\
POST  & \texttt{/auth/register/provider/}         & Provider signup + send OTP. \\
POST  & \texttt{/auth/otp/send/}                  & Send SMS OTP (public). \\
POST  & \texttt{/auth/otp/verify/}                & Verify SMS OTP $\rightarrow$ JWT pair. \\
POST  & \texttt{/auth/otp/email/send/}            & Send email OTP. \\
POST  & \texttt{/auth/otp/email/verify/}          & Verify email OTP $\rightarrow$ JWT pair. \\
POST  & \texttt{/auth/login/}                     & Email or phone + password login (public). \\
POST  & \texttt{/auth/token/refresh/}             & Refresh JWT access token. \\
POST  & \texttt{/auth/logout/}                    & Blacklist current refresh token. \\
POST  & \texttt{/auth/password/reset/}            & Request OTP for password reset. \\
PATCH & \texttt{/auth/password/confirm/}          & Verify OTP and reset password. \\
POST  & \texttt{/auth/google-auth/}               & Firebase ID token $\rightarrow$ JWT (public). \\
POST  & \texttt{/auth/fcm-token/}                 & Register the device FCM token. \\
PATCH & \texttt{/auth/provider/bio/}              & Provider updates bio and consultation fee. \\
\bottomrule
\end{longtable}

\section*{Appendix 2: Sample Environment Configuration}
\addcontentsline{toc}{section}{Appendix 2: Sample Environment Configuration}
\label{app:env-config}

The Django backend reads configuration from a \texttt{.env} file at
project root using \texttt{django-environ}. The complete set of
variables expected by Clinix is shown below. Values shown are
placeholders; real secrets must never be committed to version
control.

\begin{lstlisting}[caption={Sample \texttt{.env} for the Clinix backend}]
# ----- Core Django -----
SECRET_KEY=replace-with-50-char-random-string
DEBUG=False
ALLOWED_HOSTS=clinix-production.up.railway.app,localhost,127.0.0.1

# ----- Database (PostgreSQL) -----
DATABASE_URL=postgres://user:pass@host:5432/clinix

# ----- Cache / Channels / Celery (Redis) -----
REDIS_URL=redis://default:pass@host:6379/0
CELERY_BROKER_URL=redis://default:pass@host:6379/1
CHANNEL_LAYER_REDIS_URL=redis://default:pass@host:6379/2

# ----- JWT -----
JWT_ACCESS_LIFETIME_MINUTES=60
JWT_REFRESH_LIFETIME_DAYS=7

# ----- Firebase -----
FIREBASE_CREDENTIALS=/etc/secrets/firebase_key.json
GCP_AUDIO_BUCKET=clinix-call-recordings

# ----- Google AI (Gemini + Speech-to-Text) -----
GEMINI_API_KEY=AIza...
MEDLM_MODEL_ID=gemini-1.5-flash-latest
GOOGLE_APPLICATION_CREDENTIALS=/etc/secrets/gcp-key.json

# ----- Agora (video calls) -----
AGORA_APP_ID=your-agora-app-id
AGORA_APP_CERT=your-agora-app-certificate

# ----- CamPay (mobile money) -----
CAMPAY_BASE_URL=https://demo.campay.net/api/
CAMPAY_USERNAME=your-campay-username
CAMPAY_PASSWORD=your-campay-password
CAMPAY_WEBHOOK_URL=https://your-host/api/v1/payments/campay/webhook/

# ----- Twilio (SMS OTP) -----
TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxx
TWILIO_AUTH_TOKEN=xxxxxxxxxxxxxxxxxxxx
TWILIO_FROM_NUMBER=+12345678901

# ----- Email (OTP + password reset) -----
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_HOST_USER=noreply@clinix.cm
EMAIL_HOST_PASSWORD=app-specific-password
EMAIL_USE_TLS=True

# ----- Front-end origins (CORS) -----
CORS_ALLOWED_ORIGINS=https://admin.clinix.cm,http://localhost:5173

# ----- Defaults -----
DEFAULT_CONSULTATION_FEE_XAF=15000
DEFAULT_SERVICE_CHARGE_XAF=500
\end{lstlisting}

\subsection*{A2.1 Mobile App Configuration}

The Flutter mobile app reads its base URL and feature flags from
\texttt{lib/core/constants/api\_constants.dart} and an optional
bundled \texttt{.env} loaded via \texttt{flutter\_dotenv}:

\begin{lstlisting}[caption={Sample \texttt{.env} for the Flutter mobile app}]
API_BASE_URL=https://clinix-production.up.railway.app/api/v1/
WS_BASE_URL=wss://clinix-production.up.railway.app/ws/
GOOGLE_MAPS_API_KEY=AIza...
AGORA_APP_ID=your-agora-app-id
FIREBASE_WEB_API_KEY=AIza...
\end{lstlisting}

\subsection*{A2.2 Admin Dashboard Configuration}

The React admin dashboard reads its API base URL from a Vite
\texttt{.env} file at build time:

\begin{lstlisting}[caption={Sample \texttt{.env} for the React admin dashboard}]
VITE_API_BASE_URL=https://clinix-production.up.railway.app/api/v1
VITE_APP_TITLE=Clinix Admin
\end{lstlisting}
