{\Large\bfseries ABSTRACT}
\end{center}
\vspace{0.6cm}

Cameroon's healthcare system suffers from hospital congestion, uneven distribution of medical specialists, and a growing pool of informal, unverified online practitioners. This project presents \textbf{Clinix}, a mobile health platform built for the English-speaking regions of Cameroon. The platform connects patients with verified healthcare providers through virtual consultations, an AI-powered symptom checker that recommends a ranked list of providers, mobile-money payments via CamPay, on-demand home-care bookings, and basic health-record management. Provider credentials are cross-checked against the Cameroon Medical Council register before any provider becomes visible to patients. Clinix is implemented as a Flutter mobile application, a Django REST and Channels backend, and a React administrative dashboard, deployed on a PostgreSQL and Redis stack. The system was developed under an Agile-Scrum methodology and validated through unit, integration, and end-to-end system tests.

\vspace{0.6cm}
\noindent\textbf{Keywords:} Telemedicine, AI Consultation, Mobile Health, Cameroon.
