{\Large\bfseries ABSTRACT}
\end{center}
\vspace{0.6cm}

Cameroon's healthcare system faces significant challenges including resource limitations, uneven distribution of medical professionals, and limited access to services. This project presents \textbf{Clinix}, a comprehensive mobile health platform connecting verified healthcare providers with patients through an integrated digital ecosystem. Clinix incorporates telemedicine features including virtual consultations, AI-powered symptom analysis, appointment scheduling, and secure messaging. The platform employs a multi-tier architecture with Flutter-based mobile applications, a Django REST API backend, a React-based administrative dashboard, and a PostgreSQL database. Key features include provider credential verification, GPS-enabled facility mapping, mobile money integration, and bandwidth-optimised design. Developed using an Agile-Scrum methodology, the system achieved app loading times under three seconds with end-to-end encryption and data protection compliance. Clinix reduces hospital congestion, improves healthcare access, creates employment opportunities for verified providers, and provides culturally adapted bilingual (English/French) interfaces, contributing to mobile health solutions in the Cameroonian context.

\vspace{0.6cm}
\noindent\textbf{Keywords:} Telemedicine, Mobile Health, Healthcare Accessibility, AI Consultation, Provider Verification, Digital Healthcare, Cameroon.
